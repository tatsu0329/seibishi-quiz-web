## 📝 ファイル名の命名規則

ファイル名は以下の形式に従ってください：

```
level-{等級番号}-{燃料タイプ略称}-{年度}-{回次}.json
```

### 等級番号
- `1` = 国家1級
- `2` = 国家2級
- `3` = 国家3級

### 燃料タイプ略称
- `C` = 小型（1級のみ）
- `G` = ガソリン
- `D` = ディーゼル

### 年度と回次
- `2025-1` = 2025年度第1回
- `2025-2` = 2025年度第2回
- `2024-1` = 2024年度第1回

### 例

- `level-1-C-2025-1.json` → 国家1級 小型 2025年度第1回
- `level-2-G-2024-2.json` → 国家2級 ガソリン 2024年度第2回
- `level-2-D-2023-1.json` → 国家2級 ディーゼル 2023年度第1回
- `level-3-G-2024-1.json` → 国家3級 ガソリン 2024年度第1回

## 📄 JSONファイルの構造

各JSONファイルは以下の形式で記述してください：

```json
{
  "category": {
    "level": "国家1級",
    "fuelType": "小型",
    "year": "2025-1"
  },
  "questions": [
    {
      "id": "No.1",
      "question": "問題文をここに記入してください。",
      "choices": [
        "(1). 選択肢1の内容",
        "(2). 選択肢2の内容",
        "(3). 選択肢3の内容",
        "(4). 選択肢4の内容"
      ],
      "answerIndex": 1,
      "explanation": "解説をここに記入してください（オプション）",
      "images": ["/image/25031c/25031c-1.png"]
    }
  ]
}
```

### フィールドの詳細説明

#### `category` オブジェクト

| フィールド | 必須 | 説明 | 例 |
|-----------|------|------|-----|
| `level` | ✅ | 等級 | `"国家1級"`, `"国家2級"`, `"国家3級"` |
| `fuelType` | ✅ | 燃料タイプ | `"小型"`, `"ガソリン"`, `"ディーゼル"` |
| `year` | ✅ | 実施年度と回次 | `"2025-1"`, `"2024-2"` |

#### `questions` 配列

各問題オブジェクトのフィールド：

| フィールド | 必須 | 説明 | 例 |
|-----------|------|------|-----|
| `id` | ✅ | 問題ID（一意の識別子） | `"No.1"`, `"No.2"` |
| `question` | ✅ | 問題文 | `"Q01. 問題文..."` |
| `choices` | ✅ | 選択肢の配列（4つ） | `["(1). ...", "(2). ...", "(3). ...", "(4). ..."]` |
| `answerIndex` | ✅ | 正解のインデックス（1-4の1ベース） | `1` = 選択肢(1)が正解 |
| `explanation` | ❌ | 解説（任意） | `"解説文..."` |
| `images` | ❌ | 画像パスの配列（任意） | `["/image/25031c/25031c-1.png"]` |

### 重要な注意事項

1. **`answerIndex`は1ベースです**
   - `1` = 選択肢(1)が正解
   - `2` = 選択肢(2)が正解
   - `3` = 選択肢(3)が正解
   - `4` = 選択肢(4)が正解

2. **選択肢は必ず4つ必要です**

3. **問題ID（`id`）は一意である必要があります**

## 🖼️ 画像の配置方法

### 画像の保存場所

画像は `public/image/` ディレクトリに保存してください。

### ディレクトリ構造の推奨

```
public/image/
  └── {年度}{等級}{燃料タイプ}/
      ├── {年度}{等級}{燃料タイプ}-1.png
      ├── {年度}{等級}{燃料タイプ}-2.png
      └── ...
```

### 例

- `level-1-C-2025-1.json` の場合：
  - ディレクトリ: `public/image/25031c/`
  - 画像パス: `["/image/25031c/25031c-1.png"]`

- `level-2-G-2024-2.json` の場合：
  - ディレクトリ: `public/image/24032g/`
  - 画像パス: `["/image/24032g/24032g-1.png"]`

### 画像パスの命名規則

```
/image/{年度}{等級番号}{燃料タイプ略称}/{年度}{等級番号}{燃料タイプ略称}-{問題番号}.png
```

**年度の変換：**
- 2025年 → `25`
- 2024年 → `24`
- 2023年 → `23`

**例：**
- 2025年度第1回 国家1級 小型 → `25031c`
- 2024年度第2回 国家2級 ガソリン → `24032g`
- 2023年度第1回 国家3級 ディーゼル → `23033d`

## 🚀 問題集を追加する手順

### ステップ1: JSONファイルを作成

1. `TEMPLATE.json` をコピーして、新しいファイル名にリネーム
2. ファイル名は命名規則に従う（例: `level-1-C-2025-1.json`）
3. JSONファイルを編集して問題を追加

### ステップ2: 画像を配置（必要な場合）

1. `public/image/` ディレクトリに適切なフォルダを作成
2. 画像ファイルを配置
3. JSONファイルの `images` フィールドに画像パスを記入

### ステップ3: `src/data/index.ts` を更新

1. `src/data/index.ts` を開く
2. 新しいJSONファイルをインポート
3. エクスポート配列に追加

#### 例：`level-1-C-2025-1.json` を追加する場合

```typescript
// src/data/index.ts の先頭に追加
import level1C20251 from "./questionSets/level-1-C-2025-1.json";

// エクスポート配列に追加（適切な位置に）
export default [
  // 国家1級
  level1C20251, // ← ここに追加
  level1C2023,
  level1C20212,
  // ...
];
```

### ステップ4: 動作確認

1. 開発サーバーを起動（`npm run dev`）
2. ブラウザでサイトにアクセス
3. `/select` ページで新しい問題集が表示されることを確認
4. 問題集を選択して、問題が正しく表示されることを確認

## 📋 テンプレートファイルの使用

`TEMPLATE.json` ファイルをコピーして使用することで、正しい形式で問題集を作成できます。

1. `TEMPLATE.json` をコピー
2. 適切なファイル名にリネーム
3. 内容を編集

## ✅ チェックリスト

新しい問題集を追加する際は、以下を確認してください：

- [ ] ファイル名が命名規則に従っている
- [ ] JSONファイルの形式が正しい（構文エラーがない）
- [ ] `category` オブジェクトの値が正しい
- [ ] すべての問題に `id`, `question`, `choices`, `answerIndex` が含まれている
- [ ] `answerIndex` が1-4の範囲内である
- [ ] 選択肢が4つすべて含まれている
- [ ] 画像を使用する場合、画像パスが正しい
- [ ] `src/data/index.ts` にインポートとエクスポートを追加した
- [ ] 動作確認を実施した

## 🔍 トラブルシューティング

### JSONファイルが読み込まれない

- JSONファイルの構文エラーを確認（カンマの位置、引用符など）
- ファイル名が正しいか確認
- `src/data/index.ts` に正しくインポート・エクスポートされているか確認

### 画像が表示されない

- 画像パスが正しいか確認（`/image/...` で始まる）
- 画像ファイルが `public/image/` ディレクトリに存在するか確認
- 画像ファイル名が正しいか確認

### 問題が表示されない

- `category` の値が正しいか確認
- `questions` 配列が空でないか確認
- ブラウザのコンソールでエラーを確認
